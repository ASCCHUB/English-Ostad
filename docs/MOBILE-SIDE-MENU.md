# Mobile side menu and simple Home

Mobile bottom navigation is removed. A closed-by-default left drawer opens only from the Menu button; navigation therefore takes an intentional open and selection. It contains Home, All lessons, Quick exam, Topics, Play, My Stars, How to use, Share app and parent access. It closes on selection, outside tap, close button or Escape. Desktop navigation remains in its sidebar.

During active lessons, the Menu button is placed in the existing lesson toolbar so it does not overlay answers or add a floating button. Home has a greeting and only the main Continue, Quick exam and All lessons actions. The class map is on All lessons. Sharing and the guide remain in the menu and desktop footer.

Quick exam replaces Find my level, with the requested Pashto wording on Home, the exam intro and mobile menu. The first-time guide uses the same label. Completed assessment results, scores and all-lesson access are preserved.

Validation: drawer open/closed rendering, simple Home without the map or bottom bar, exam route and inline lesson menu pass; 143 tests pass; Android CSS compatibility guard and APK build pass; APK signature and bundled asset version are verified.
